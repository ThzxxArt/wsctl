# 0.2.0 性能基线

测量脚本：`python scripts/benchmark.py --sessions 8 --lines 200000 --idle-sessions 100`

| 指标 | 0.2.0 | 目标 |
|---|---|---|
| T1 `seq 1 200000`（真实 PTY + `/ws/v2`） | **236 ms** | ≤ 6000 ms |
| 8 个会话各跑 20 万行（总耗时） | **1758 ms** | ≤ 20000 ms |
| 单会话 p50 | **219 ms** | — |
| attach 到 `attached` | **91 ms** | — |
| 断线续传（`last_seq` 命中） | **1.8 ms** | p95 < 300 ms |
| 100 空闲会话 RSS 增量 | **0.3 MiB** | < 250 MB |
| 单空闲会话 RSS 增量 | **~3 KiB** | < 1.5 MB |
| 首屏 JS（gzip，不含懒加载） | **393.2 KiB** | < 500 KiB |

## 说明

- 这是开发机上的**可重复 smoke 基线**，不是跨机器硬门槛；
- CI 只硬性检查 bundle budget 与功能不变量，性能数值变化记录在本文件；
- 真实浏览器中的 xterm 渲染、WebGL 回退与重连由 Playwright 场景覆盖；
- 测量环境：Python 3.13.5，FastAPI TestClient（进程内 ASGI + 真实 PTY），
  8 MiB scrollback。
- 100 空闲会话测量：创建 100 个 `/bin/sh` 会话后进程 RSS 增量 0.3 MiB
  （约 3 KiB/会话；malloc 复用使该值在 0–4 MiB 间波动，绝对上限仍是
  每会话 < 1.5 MB）。

## 复现

```bash
python scripts/benchmark.py --sessions 8 --lines 200000 --idle-sessions 100
```

输出 JSON，可直接替换 `docs/benchmarks/0.2.0.json` 中的数值。
